# Domain language

Canonical definitions live in `docs/INDEX.md` and its owning documents. This
file is only a compact vocabulary pointer.

- **Episode YAML** — the single agent-authored executable stage script.
- **Instance** — a friendly episode-local name bound to one immutable asset.
- **Asset** — a versioned reusable figure, voice, set, prop, or dressing entry.
- **Procedure** — a registered typed performance that owns its animation,
  timing defaults, constraints, and state transition.
- **Statement** — one actor's dialogue or ellipsis-only silent beat.
- **Inline call** — a formal procedure call embedded at its synchronization
  point in spoken text; it is absent from speech audio and subtitles.
- **Brace group** — an exact audio boundary where typed calls begin together.
- **Staging** — automatic composition derived from location and relationships.

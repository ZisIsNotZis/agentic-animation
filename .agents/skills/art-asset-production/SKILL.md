# art-asset-production

Use when adding or reworking a **figure or set** that must meet the accepted
M1–M3 bar and be exercised through the real engine before it earns a production
path. Asset formats and milestone scope are owned elsewhere; this skill owns the
reusable production procedure and its evidence discipline.

Read first: [docs/7_SCHEMAS.md](../../../docs/7_SCHEMAS.md) (Figure artwork; Set
world declarations), [docs/6_WORLD_PLUGIN_CONTRACT.md](../../../docs/6_WORLD_PLUGIN_CONTRACT.md)
(library layout), the current milestone contract under `docs/`, and
[docs/0_ROADMAP.md](../../../docs/0_ROADMAP.md)
(scope, comparison budget, Art/Function/Production dimensions).
Not for: staging (`camera-staging`), prose→episode (`text-to-episode`), or
checking already-built assets (`qa-stills`).

## 1. Iterate in a disposable draft library, never in place

`anim` resolves config and paths from `--cwd`, so a scratch root is a full
engine driven by a throwaway library. Replace only the draft copy of the asset
under `$S/library/`; leave the repository untouched until acceptance.

```sh
S=/tmp/draft-<name>                 # put it in the evidence bundle when it must survive
mkdir -p "$S/episodes"
cp -r library "$S/library"
cp anim.config.json "$S/anim.config.json"
ln -s "$PWD/vendor" "$S/vendor"
cp -r episodes/<slug> "$S/episodes/<slug>"
printf '{"private":true,"type":"module"}' > "$S/library/package.json"
ln -s "$PWD/node_modules" "$S/library/node_modules"
```

Run every command as
`npm run anim -- --cwd "$S" check|make "$S/episodes/<slug>/episode.yml"`.
The last two shims are required, not optional: `library/*/plugin.js` imports
`@anim/core/stdlib` as ESM, so the draft library needs its own `type: module`
marker and a `node_modules` link or asset loading fails. The shims are draft
material — never commit them.

## 2. Author and declare the art

- **Set** `library/set/<name>/`: one painted `<g id>` group per declared layer,
  a declared `foreground` layer for near-camera occlusion, and
  `data-support-top="<y>"` on the element named by `supports[].paint`. The
  loader validates layer ids, `coordinateSpace`, `safeActorArea` and `supports`
  (`viewBox == coordinateSpace`, painted-vs-declared tolerance 8); the exact
  rules live in [docs/7_SCHEMAS.md](../../../docs/7_SCHEMAS.md). Declare exactly one support per name — the loader
  does not reject duplicate support names and resolves to the last match,
  silently changing the rest surface (M3 probe).
- **Figure** `library/figure/<name>/`: `skeleton.json` plus per-view
  `artwork.json` in the allowlisted `svg-bone-parts` format, with sockets and
  hand/eye/mouth shapes. The committed draft is generated by
  `tools/art-direction-study/lin_parts.py`; extend the generator instead of
  hand-editing the large JSON.
- Keep the accepted direction's palette and style anchor (M1 B-direction,
  `figure/lin_b_draft`) so the new asset belongs with the accepted figure.
- Record `provenance` (artwork origin, license, style anchor, support
  agreement) in the set manifest. Original vector artwork only — no AI, paid or
  raster sources.

## 3. Prove it loads and declared==painted

`npm run anim -- --cwd "$S" check ...` must pass. Confirm the guard actually
bites by planting a red case: move `supports[].y` off by more than 8 and watch
`check` fail loud (`support "X" declared at y … but painted at …`). The M2
y450-vs-y390 defect is exactly this class; a green check is what makes the set
and its painted geometry agree.

## 4. Stills-first QA loop

Render targeted stills at matched narrative beats first (1280×720 @24), inspect
each at full resolution, fix at the owning layer, and iterate 2–3 times before
spending on clips. Then run the gate in [qa-stills](../qa-stills/SKILL.md). A
green `check` never substitutes for looking at the frame. Judge the canonical
render (`anim preview`/`render-yaml` output), not the Studio storyboard, whose
legacy composition draws placeholder sets and no library art.

## 5. Archive a durable evidence bundle

Evidence lives outside the repo, never in Git. Minimum contents:

- `MANIFEST.md` — every acceptance criterion mapped to its exact evidence file.
- `receipt.json` — per-column revisions, gate results, SHA256 of every artifact.
- `index.html` + `CHECKLIST.md` — a human entry with an itemized AV/verdict
  checklist and an explicit milestone-judgment question.
- matched-beat comparison plates: original → last accepted → candidate, with
  frame/time mappings.
- a frame proof that runs the **real evaluator** at the sampled frames and
  includes an in-flight red case that must fail; a pixel ratio or other proxy is
  not evidence for the source.
- honest disclosure of modality limits and anything not re-exercised, and a
  failing criterion recorded as failing and routed to its owner.
- a later bundle reuses a draft library by symlinking its single home and
  binding it by hash, not by copying it.

## Validated vs untested

Validated on the real path in M2/M3: the overlay mechanism, `check`/`make` and
bounded renders on the draft library, the declared==painted guard with its red
case, layered set/figure consumption, comparison plates and the evaluator frame
proof. Untested: `lin_parts.py` is a study script, not a supported CLI, and
every new asset still needs its own independent review and user gate.

Completion: `check` passes on the draft library, targeted stills pass the
qa-stills gate, the bundle's criterion→evidence map is complete with red cases
disclosed, and the production asset path is not replaced without approval.
